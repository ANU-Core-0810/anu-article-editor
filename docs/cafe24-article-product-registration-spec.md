# Cafe24 Article Product Registration Spec

작성일: 2026-07-02

기준 파일: `/Users/yong-woo/Downloads/excelUploadProductDefault-2.csv`

Notion 세팅 상태: 2026-07-02 기준 `아티클 DB`에 Cafe24 등록 준비 컬럼 추가 완료.
`아티클코드`는 formula가 아니라 사람이 직접 입력하는 텍스트 속성으로 전환했다.

아티클 이미지 R2 공개 도메인:

```text
https://pub-14eaf4c4a9324927bf2879a272de972a.r2.dev
```

Notion에는 이미지 경로를 별도로 입력하지 않는다.
GAS가 `아티클코드`를 기준으로 에셋 폴더와 대표 이미지 경로를 자동 생성한다.

```text
아티클코드: ARTI26-001
```

GAS 출력 시에는 아래처럼 변환한다.

```text
에셋 폴더: /2026/arti26-001/
대표 이미지 상대 경로: /2026/arti26-001/cover.jpg
대표 이미지 URL: https://pub-14eaf4c4a9324927bf2879a272de972a.r2.dev/2026/arti26-001/cover.jpg
```

## 결론

Cafe24 상품 **등록용** 엑셀/CSV 양식은 고정 헤더를 사용한다.
따라서 아티클 전용으로 컬럼을 삭제한 CSV를 만드는 방식이 아니라, **Cafe24가 요구하는 102개 헤더를 그대로 유지하고 필요한 값만 채운다.**

상품정보 **추출/수정용** 양식은 항목 선택이 가능하지만, 신규 등록용 기본 양식은 별도다.

## 운영 구조

```text
Notion 아티클 DB
  메타데이터, 카페24 등록 추적, 관련 제품, 관련 아티클

Notion 아티클 편집기
  원고 작성, HTML 변환 결과, 피드백

Google Sheet / Apps Script
  Notion 동기화, HTML 변환, Cafe24 등록용 CSV 생성

Cafe24
  상품 등록 CSV 업로드
  등록 후 생성된 상품번호/상품코드를 Notion에 역기록
```

## 중요한 변경점

등록용 CSV에는 아래 컬럼이 없다.

- `상품번호`
- `상품명(기본몰)`
- `공급사명`
- `브랜드명`
- `제조사명`
- `상품등록일`
- `최근수정일`
- `조회수`, `좋아요수`, `장바구니수` 등 통계 컬럼

따라서 신규 등록 시에는 Cafe24가 생성하는 값을 등록 이후 다시 가져와 Notion에 기록해야 한다.

## 관련상품 / 이어볼 아티클 처리

등록용 기본 CSV에는 관련상품/추가구성상품 컬럼이 보이지 않는다.

따라서 아래 작업은 상품 등록 CSV와 분리한다.

| 목적 | Notion 기준 | Cafe24 기능 | 처리 방식 |
|---|---|---|---|
| 관련 상품 | `아티클 DB.관련 제품` -> 상품 DB `카페24 상품번호` | 관련상품 | 상품 등록 후 별도 연결 |
| 이어볼 아티클 | `아티클 DB.관련 아티클` -> 연결 아티클 `카페24 상품번호` | 추가구성상품 | 상품 등록 후 별도 연결 |

권장 운영:

1. 아티클 상품을 등록한다.
2. Cafe24에서 생성된 `상품번호`, `상품코드`를 Notion `아티클 DB`에 기록한다.
3. 관계 연결용 별도 시트에서 관련상품/추가구성상품 연결 대상을 만든다.
4. Cafe24 API, 관리자 수동 설정, 또는 상품 수정용 엑셀 양식에서 관계 컬럼 지원 여부를 확인해 후처리한다.

현재 상태:

- 관련상품/추가구성상품 자동 연결은 보류한다.
- `아티클 DB.관련 제품`, `아티클 DB.관련 아티클` relation은 유지하되, GAS 1차 테스트에서는 등록 CSV에 반영하지 않는다.
- 상품 DB에는 현재 `카페24 상품번호` 컬럼이 확인되지 않았다. 후속 단계에서 관련상품 자동화를 재개할 때 상품 DB에 `카페24 상품번호`를 추가하거나 기존 식별 컬럼을 확정한다.

### 2-1. 아티클 코드/이미지 경로 생성 규칙

상품관리 쪽과 동일하게 R2 공개 URL을 사용하되, Notion에는 이미지 경로나 에셋 폴더명을 따로 입력하지 않는다.
GAS가 `아티클코드`만으로 연도 폴더, 아티클 폴더, 대표 이미지 경로를 만든다.

예:

```text
아티클코드: ARTI26-001
```

GAS는 아래 상수를 사용해 Cafe24 등록 CSV에 들어갈 이미지 URL을 만든다.

```js
const ARTICLE_R2_BASE_URL = 'https://pub-14eaf4c4a9324927bf2879a272de972a.r2.dev';

function normalizeArticleCode(code) {
  return String(code || '').trim().toLowerCase();
}

function getArticleYearFolder(articleCode) {
  const normalized = normalizeArticleCode(articleCode);
  const match = normalized.match(/^arti(?:cle)?-?(\d{4}|\d{2})/);
  if (!match) {
    throw new Error(`Invalid article code: ${articleCode}`);
  }

  return match[1].length === 2 ? `20${match[1]}` : match[1];
}

function getArticleAssetFolder(articleCode) {
  return `/${getArticleYearFolder(articleCode)}/${normalizeArticleCode(articleCode)}/`;
}

function getArticleCoverPath(articleCode) {
  return `${getArticleAssetFolder(articleCode)}cover.jpg`;
}

function getArticleImageUrl(articleCode) {
  return `${ARTICLE_R2_BASE_URL}${getArticleCoverPath(articleCode)}`;
}
```

결과:

```text
https://pub-14eaf4c4a9324927bf2879a272de972a.r2.dev/2026/arti26-001/cover.jpg
```

자동 생성한 대표 이미지 하나를 Cafe24의 `이미지등록(상세)`, `이미지등록(목록)`, `이미지등록(작은목록)`, `이미지등록(축소)`에 동일하게 매핑한다.

## Apps Script 처리 순서

1. Notion에서 `아티클 DB.상태`가 `시작 전`, `작성 중`이 아닌 항목과 연결된 `아티클 편집기`를 가져온다.
2. 연결된 편집기 페이지 중 `변환 상태 = 변환 요청`이거나 `HTML 출력`이 비어 있는 페이지를 HTML로 변환한다.
3. 변환 HTML을 `아티클 편집기.HTML 출력`에 다시 기록한다.
4. `아티클 DB` relation과 편집기 relation을 합쳐 `Articles` 검수 행을 만든다.
5. `상태 = 등록 중`이면 등록용 102개 헤더 순서대로 row를 생성한다.
6. `상태 = 업데이트`이면 수정용 row를 생성한다. 수정용은 맨 앞에 `상품번호`를 추가하고 `상품코드`에는 Notion `카페24 상품코드`를 넣는다.
7. Notion 값, 자동 생성값, 고정값을 채운다.
8. 관련상품/이어볼 아티클은 등록 CSV에 넣지 않고 `relation_tasks`에 별도 기록한다.
9. Cafe24 업로드 후 생성된 `상품번호`, `상품코드`를 Notion에 역기록한다.
10. 상품번호가 확보된 뒤 관련상품/추가구성상품 연결을 후처리한다.
